# **App Name**: CargoCalc

## Core Features:

- Vehicle Dimensions Input: Input vehicle dimensions (length, width, height of cargo area).
- AI Vehicle Dimensions Lookup: Use AI to search for vehicle cargo dimensions based on make, model, and year if the car is not on the list. This acts as a tool.
- TV Dimensions Input: Input TV dimensions (width, height, depth of the TV box).
- Fit Calculation: Calculate if the TV box fits inside the vehicle cargo area based on dimensions.
- Fit Result Display: Display a clear 'Fits' or 'Doesn't Fit' message with visual cues (e.g., green checkmark or red X).
- AI-Powered Suggestions: Use AI to suggest alternative TV sizes or vehicle loading configurations that might work, acting as a helpful 'tool'.
- Saved Vehicles: Allow users to save commonly used vehicle dimensions for quick access.

## Style Guidelines:

- Primary color: Dark teal (#2A9D8F) to give a sense of trust.
- Background color: Very light teal (#E9F5F4), almost white, providing a clean backdrop.
- Accent color: A contrasting dark orange (#E76F51) for alerts like 'Doesn't Fit' message.
- Body and headline font: 'Inter', a sans-serif for clear, modern readability.
- Use simple, intuitive icons for vehicle and TV dimensions, as well as fit results.
- Keep the layout clean and straightforward, focusing on easy input and clear results. Consider a responsive design.
- Subtle transitions when displaying results, confirming inputs and selections, and loading the page, making use of the floating element animations popular on contemporary web designs.
